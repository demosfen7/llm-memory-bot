# Telegram-бот с долговременной памятью LLM

Telegram-бот на базе OpenAI, который помнит разговор с каждым пользователем.
История диалога и краткая заметка о пользователе хранятся в SQLite, поэтому бот
продолжает беседу с того же места даже после перезапуска.

## Возможности

- Отвечает на сообщения с учётом последних 10 реплик диалога.
- Сам ведёт короткую заметку о пользователе: имя, цели, предпочтения, важные факты.
  Заметка обновляется каждые 10 сообщений и помогает помнить ключевое, даже когда
  оно давно ушло из истории.
- Хранит память отдельно для каждого пользователя.
- Сохраняет всё на диск: после перезапуска ничего не теряется.
- Забывает всё о пользователе по команде `/reset`.
- Понятно сообщает об ошибках: неверный ключ OpenAI, исчерпанный лимит, нет связи.
- Пишет в консоль входящие сообщения и ответы, не показывая токены и ключи.

В комплекте есть и `bot_no_memory.py` — облегчённый вариант бота без хранения истории:
каждое сообщение он обрабатывает отдельно, без контекста и без базы данных.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | Рассказывает, что умеет бот |
| `/reset` | Удаляет историю и заметку о пользователе. Ответ: «Память очищена. Начинаем с чистого листа.» |

## Как устроено

```text
llm-memory-bot/
├── bot_memory.py      # бот с памятью: команды и обработка сообщений
├── bot_no_memory.py   # вариант без памяти
├── database.py        # хранение истории и заметок в SQLite
├── llm_client.py      # запросы к OpenAI и составление заметки о пользователе
├── config.py          # чтение настроек из .env, настройка логов
├── requirements.txt
└── .env.example       # шаблон настроек
```

Логика разделена на три слоя: Telegram (`bot_*.py`), модель (`llm_client.py`) и
хранилище (`database.py`).

### Обработка сообщения

1. Сообщение пользователя сохраняется в базу.
2. Из базы загружаются последние 10 сообщений диалога (новое — последнее из них).
3. Загружается заметка о пользователе.
4. Заметка подставляется в системный промпт.
5. Системный промпт и история отправляются в OpenAI Chat Completions API.
6. Ответ модели сохраняется в базу.
7. Ответ отправляется пользователю.
8. Если пользователь написал уже 10, 20, 30… сообщений, модель обновляет заметку
   о нём по свежему отрезку диалога. Заметка не длиннее 500 символов.

В модель никогда не уходит больше 10 сообщений истории: так запросы остаются
быстрыми и недорогими, а заметка сохраняет главное из более ранней части разговора.

### База данных

SQLite-файл (по умолчанию `memory.db`) с двумя таблицами:

| Таблица | Содержимое |
|---|---|
| `messages` | все сообщения пользователей и ответы бота: `user_id`, `role`, `content`, `created_at` |
| `user_context` | заметка о каждом пользователе: `user_id`, `summary`, `updated_at` |

Все запросы параметризованы. Таблицы создаются автоматически при первом запуске.

## Установка

Нужен Python 3.11 или новее.

```bash
python -m venv .venv
source .venv/bin/activate  # macOS/Linux
# .venv\Scripts\activate   # Windows

pip install -r requirements.txt
cp .env.example .env       # в Windows PowerShell: Copy-Item .env.example .env
```

## Настройка

Заполните `.env`:

| Переменная | Обязательна | Значение |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | да | токен бота от BotFather |
| `OPENAI_API_KEY` | да | ключ OpenAI API |
| `OPENAI_MODEL` | нет | модель, по умолчанию `gpt-4o-mini` |
| `DATABASE_PATH` | нет | путь к базе, по умолчанию `memory.db` в папке проекта |

Если обязательная переменная не задана, бот сообщит об этом и не запустится.

### Токен Telegram

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Введите имя бота и username, который заканчивается на `bot`.
3. Скопируйте присланный токен в `TELEGRAM_BOT_TOKEN`.

### Ключ OpenAI

1. Войдите на [platform.openai.com](https://platform.openai.com/) и пополните баланс
   в разделе Billing.
2. На странице [API keys](https://platform.openai.com/api-keys) нажмите
   «Create new secret key».
3. Скопируйте ключ в `OPENAI_API_KEY` (он показывается только один раз).

## Запуск

Бот с памятью:

```bash
python bot_memory.py
```

Вариант без памяти:

```bash
python bot_no_memory.py
```

Остановка — `Ctrl+C`. Один токен Telegram может использовать только одна запущенная
программа, иначе Telegram вернёт ошибку `Conflict`. Чтобы держать оба бота включёнными
одновременно, создайте у BotFather второго бота и запустите копию проекта с другим `.env`.

Посмотреть, что бот запомнил о пользователях:

```bash
sqlite3 memory.db "SELECT user_id, summary, updated_at FROM user_context;"
```

## Безопасность

`.env` содержит токен и ключ, а `memory.db` — личные сообщения пользователей.
Оба файла исключены через `.gitignore` и не должны попадать в репозиторий.
Если ключ всё же утёк, отзовите его: токен — командой `/revoke` у BotFather,
ключ OpenAI — на странице API keys.
